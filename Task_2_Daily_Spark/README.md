# Daily Spark — Random Quote Generator

A Flutter quote application for discovering inspiring quotes, saving favorites, and creating personal quotes.

## Features
- Random quotes with author and category
- Favorites and category filtering
- Create, search, and delete custom quotes
- Copy quotes
- Mindful reflection breathing timer
- Local persistence
